## About me

Information Systems student based in Rio de Janeiro, focused on **backend development**.

What interests me most is the point where **APIs meet AI**: taking messy real-world data, running it through a solid backend, and putting an LLM layer on top of it. I learn by building — every concept here came from something I actually shipped and broke a few times.

---

## What I'm up to

- **Building** — an API that pulls official government gazettes, extracts structured data from raw text and answers questions about it through an LLM
- **Learning** — async, dependency injection and testing in FastAPI
- **Exploring** — LLMs, RAG and vector databases
- **Goal** — my first role in applied AI or data-heavy backend

## Projects

### [diario-oficial-rag](https://github.com/M4RC3L07969/diario-oficial-rag) &nbsp;·&nbsp; *in progress*

Question answering over Brazilian official gazettes. The pipeline collects raw publications, pulls structured fields out of them with regex, indexes the text in a vector database and answers questions through an LLM, citing the source publication.

`Python` · `FastAPI` · `Qdrant` · `Docker`

### [Campo Minado](https://github.com/M4RC3L07969/Campo-minado)

Full Minesweeper implementation in Java with a Swing interface, multiple difficulty modes, match history and a ranking system.

`Java` · `Swing` · `OOP`
